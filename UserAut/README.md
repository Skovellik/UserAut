## Запуск:
1. Открыть SSMS
2. Выполнить скрипт из файла DataBase.sql (создание БД с таблицей и ее заполнением)
3. Открыть проект через файл .sln
4. Добавить пакеты NuGet EF6 (их достаточно, на них и работаем)
5. Добвать ADO
6. ВАЖНО! Проверь строку подключения в 'App.Config'. Работает через '.\SQLEXPRESS' !ПРОВЕРЬ! (искать '<connectionStrings>' -> 'Data Source=...')
7. Запуск
